# Security Policy

## Supported Versions

Security fixes are applied on the `main` branch.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting flow for this repository:

- Open the repository's `Security` tab.
- Choose `Report a vulnerability`.
- Include affected URLs or files, reproduction steps, impact, and any suggested remediation.

Do not open a public issue for a security report.

If private reporting is temporarily unavailable, use the contact form on [andrewpucci.com](https://andrewpucci.com/contact/) and mention that the message is a security report. Do not include sensitive exploit details there unless necessary to reproduce the issue.

## Response Expectations

Reports will be reviewed as time permits. Valid reports will be acknowledged, triaged, and fixed or mitigated as appropriate.
